## 复现命令

在包根目录PowerShell执行正常参考检查：

```powershell
.\scripts\run-reference-cangjie.ps1 -SdkHome '<SDK根目录>' -OutputDirectory '.\validation\reference-new'
```

开发验收可运行（Python3.9+；输出和scratch需是新的或空目录）：

```text
python tests/verify_reference_faults.py --sdk-home <SDK根目录> --output validation/faults-new --scratch <独立临时目录>
```

脚本会要求预测与实际失败集合一致，且编译成功、没有测试遗漏／跳过／执行错误；预测单独标记，不冒充实测。正确参考实现和测试的文件哈希在整个改错过程中必须不变。
