# 第七周与第八周进度汇报

汇报人 蔡俊杰  
整理日期 2026年11月4日

## 第七周

负责 Java 测试骨架提取和参考仓颉测试。

### 1. Java 测试骨架提取

1. 使用 JDK 语法树接口解析 Java 文件，支持单个文件和目录输入。
2. 保留包、导入、类、字段及初始化、方法签名和注解，将方法体替换为明确占位。
3. 输出 Java 骨架和 `members.json`，保存原始方法体、成员角色、签名及源码与骨架位置对应关系。
4. 使用账户、矩形、指令解析三个业务测试类验收，共提取27个成员，包括24个测试方法、1个初始化方法、1个辅助方法和1个字段。
5. 核对重载、嵌套类、构造器委托等结构，原方法体回填后与原文件逐字节一致。

### 2. 参考仓颉测试

1. 整理三个模块的24个参考测试，对照 Java 测试的输入、操作和预期结果。
2. 编译运行参考业务实现和测试，24项全部通过。
3. 在独立业务副本中分别加入取款加钱、共享边判断错误、INC 映射错误、取款失败后错误扣费四种错误，参考测试均发现了相应错误。
4. 保存编译与测试日志、逐项结果、源码哈希和错误补丁。

### 3. 运行与交付

1. 将提取器、Java 业务代码和测试合并为标准 Maven 项目，支持 VS Code 的 Run Test 和测试面板。
2. Java 共30项测试通过，包括24项业务测试和6项提取器自测。
3. 配置仓颉全部、单个方法及按测试类运行的任务，补充使用说明和复现文档。

## 第八周

负责项目选取、Java 测试骨架提取，以及 Java 骨架到仓颉骨架的翻译。

### 1. 项目选取

1. 选定 Smart Library 图书借阅管理系统和 Apache Commons IO，保存固定提交的源码、测试、资源和来源说明。
2. Smart Library 首轮选取借阅资格测试类，覆盖会员为空、未激活、借满上限、有逾期和正常可借五种情况。
3. Commons IO 首轮选取 BOM 测试类，覆盖构造、字节访问、编码名称和比较等行为，并包含三个静态对象夹具。
4. Java 原测试验证中，Smart Library 的借阅资格和罚款策略两组测试合计14项通过，Commons IO 所选测试类9项通过。罚款的参数化用例作为扩展材料保留。

### 2. Java 测试骨架提取

1. 复用第七周提取器，通用输入为 Java 文件或目录，可包含测试、基类和辅助源码。
2. 通用输出包括 Java 骨架、原始源码副本、`members.json` 和提取报告，供下游定位成员、取得原方法体并组织上下文。
3. 本批借阅资格测试提取5个成员，BOM 测试提取12个成员，合计17个成员，包括14个测试方法和3个字段。

### 3. Java 骨架到仓颉骨架翻译

1. 采用模型骨架翻译流程，输入 Java 骨架、成员表、通用规则、项目约定与相关上下文，明确输入组织、目标声明和成员交接要求。
2. 补充模型骨架翻译提示词，结合项目类型约定生成两份仓颉测试骨架。
3. 输出源目标成员对应、目标文件和位置，以及方法体或字段初始化的待填槽，方便后续整体翻译按位置装配。
4. 提供本批骨架检查程序，核对成员遗漏、重复、测试声明和占位形式，17条成员对应检查通过。
5. 两份仓颉骨架均编译通过，测试发现分别识别5项借阅资格测试和9项 BOM 测试。

本批仓颉方法体保留占位，测试发现结果用于核对声明。Commons IO 的业务类型暂用独立声明进行结构编译，实际接口仍待绑定。
