## 已知差异与未覆盖项

- Java int对应仓颉Int64，但公共对应输入域限制为Java int范围；解析器显式做int32边界检查。
- Java getter对应仓颉只读属性；Java null对应仓颉Option.None适配入口。
- 数组检查内容和顺序，不把对象身份当作数组内容相等。
- 不覆盖浮点容差、一般对象相等／身份、Unicode数字、并发、数据库与网络。Rectangle的null参数不在对应范围。
- 官方SDK在本机启动异常；参考测试通过使用的是独立localfix副本。修改内容、哈希及原版失败记录均保留；本报告没有宣称官方环境已修复。
- 本批是简单材料准备，不是LLM测试翻译方法或完整benchmark评测成果。
