# 第三项任务：ReCodeAgent 论文阅读

先读[研读正文](../references/reading/recodeagent/论文研读.md)。本周将论文阅读列为独立交付任务，与两个已实现工具分别验收；它不是额外实现出来的第三个工具。

## 按问题阅读

1. 阅读正文“一、二”：为什么仓库翻译需要分析、规划、翻译和验证？写出每阶段输入和输出，而不只记角色名称。
2. 阅读“三”：对照固定提交的入口、角色、提示模板和查询工具。区分Python代码确实执行的操作与提示词要求模型完成的操作。
3. 阅读断言与测试比较部分：如果仓颉测试删掉异常检查后通过，为什么仍不能算正确翻译？对照账户余额不足样例，列出不能丢掉的断言和后续操作。
4. 阅读项目借鉴与限制：上下文选择、执行报告分别对应哪些思路？哪些能力尚未实现？

## 文件分别怎么用

|文件|用途|
|---|---|
|论文研读.md|研究问题、整体流程、模块与源码位置、断言检查及项目借鉴|
|source_manifest.json|固定阅读的官方源码文件与提交版本，追溯依据|
|repository_metadata.json|所读代码仓库的元信息|
|ReCodeAgent_研读核对记录.json|静态核对条目与状态，不能当作运行结果|
|manifest.sha256|本目录文件的完整性摘要|

最终人工阅读确认仍待完成。验收建议是由负责人解释上述四个问题，并结合一条账户测试说明论文思想如何用于本项目。没有运行作者系统或复现论文统计，不将静态阅读写成实验复现。
