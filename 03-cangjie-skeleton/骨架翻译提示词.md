# Java 测试骨架翻译提示词

读取本批 Java 骨架、members.json，以及项目接口、转换规则和相关上下文。仅转换测试类的目标声明。每个源成员必须可追踪到目标文件、类、成员和填充位置。若类型、注解或生命周期语义缺少依据，列为待解决项。

普通 JUnit 测试类用仓颉 @Test，普通测试方法用 @TestCase，保留测试名。把无参 void 方法映射为无参 Unit 方法。保留静态和不可变字段的声明意图。外部对象构造待绑定时，使用 Option 和 None 标记初始化槽并记录原表达式。每个待填方法抛出含 SKELETON_PLACEHOLDER 和成员名的异常。按项目输出 .cj 文件和成员对应信息。

每次使用时另行提供该项目的 Java 骨架目录、成员表、目标包名和适用规则。本批实际参数见生成记录。
