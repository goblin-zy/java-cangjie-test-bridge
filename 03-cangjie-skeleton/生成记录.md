# 骨架翻译生成与修订记录

正式流程为 Java 骨架与成员表、三类相关材料及任务配置交给模型，模型输出仓颉骨架、源目标成员对应和翻译报告，再进行程序检查和编译核对。

当前 model-output 的两份样例来自此前会话按简版提示词的生成，成员对应和编译、发现记录也属于该批。此次完善提示词，按输入、处理、输出明确材料选择、处理步骤及交接字段。已有样例尚待按修订提示词重新生成或补充验收，不能把旧记录视作新版提示词的验收结果。

本批输入和包名分别为 Smart Library 借阅资格测试与 week8_library、Commons IO BOM 测试与 week8_io。Commons IO 静态夹具的真实构造接口待绑定，compile-support 中的临时类型用于既有结构检查。check_skeleton.py 当前仅核对这两份候选。

正式材料包括模型提示词、输入文件、样例输出、成员对应和检查程序。规则转换工具已移出本地正式交付范围。
