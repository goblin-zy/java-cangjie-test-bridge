# 本批骨架生成记录

本次会话按随附提示词和两份成员表生成 model-output 下的两份候选骨架。生成时依据飞书第八周的模型环节。成员对应位置由检查程序从实际产物核对并记录。规则版 java_to_cangjie_skeleton.py 也随包提供，供同学复用；本批模型候选与规则版入口分别保存。

Smart Library 首轮选择 5 项普通借阅资格测试。罚款原测试的 9 个参数化用例保存在项目源代码中，后续需要先确定预处理约定。Commons IO 选择 9 项 BOM 测试，静态字段采用可填初始化槽。compile-support 中的 ByteOrderMark 仅供本批编译检查，真实业务类型和方法体仍待接入。

Java 原测试的运行结果、仓颉编译和 dry-run 测试发现日志见 validation。此次交接提供填充阶段可直接引用的骨架与成员对应表。

本批使用 02-java-skeleton 中的两个提取目录，目标包分别为 week8_library 和 week8_io。换项目时，规则版 `java_to_cangjie_skeleton.py` 可通过 `--input` 指向其他提取目录，通过 `--package` 和 `--rules` 设置目标包、类型、名称或继承映射，并通过 `--output` 指定新目录。它支持普通类、字段、辅助方法签名、无参 void 测试和生命周期，遇到超出范围的结构会报告诊断。本批 `check_skeleton.py` 绑定借阅资格与 BOM 两份模型候选。
