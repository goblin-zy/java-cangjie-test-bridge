# 依赖与来源

Python 代码仅使用标准库。Java 部分使用随包 JavaParser、SymbolSolver、Gson 等 JAR；文件与摘要见 vendor/java-libs/manifest.json，已有许可/POM 材料在 vendor/licenses。第三方原文件名和兼容版本保留。

工具延续 week7 的具体测试上下文查找思路，采用源码快照、项目结构索引、按需读取和保留未解析状态。本项目既有的目录扫描、位置身份和查询实现按当前职责整理。JavaParser/SymbolSolver 的组合类型求解借鉴项目公共材料工具的本地解析方式，未执行公共材料模块自身流程。

AlphaTrans 的 schema 与上下文选取、ReCodeAgent 的项目分析与按问题补查提供设计参考；没有接入它们的服务/API，也没有实现 AlphaTrans 的源代码重构或可执行前缀改写。

样例工程许可与来源放在样例自身目录；既有译文证据仅供参考，不把其运行结论当作本工具自动证明。
