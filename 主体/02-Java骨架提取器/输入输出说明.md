# Java 骨架提取器的输入和输出

入口文件是 [JavaTestSkeletonExtractor.java](tools/JavaTestSkeletonExtractor.java)。它读取 Java 源码，保留包、导入、类、字段、注解和方法声明，将有实现的方法体替换为占位代码，并把原实现保存到成员表。

| 输入 | 用途 |
| --- | --- |
| `--input <路径>` | 一个 UTF-8 Java 文件，或一个包含 Java 文件的目录。目录模式递归读取 `.java` 文件。 |
| `--output <路径>` | 新目录或空目录。目录模式下，输出目录放在输入目录之外。 |
| JDK 17 | 通过 JDK 的 javac 语法树接口按 Java 17 解析。提取阶段只进行语法解析，测试依赖不参与类型求解。 |

| 输出 | 内容 |
| --- | --- |
| `original/` | 原始 Java 源码副本。 |
| `skeleton/` | Java 声明骨架。字段初始化保留，有实现的方法体改为 `SKELETON_PLACEHOLDER` 异常。 |
| `members.json` | 成员 ID、角色、签名、原方法体、字段初始化、原文与骨架位置、文件哈希和诊断。偏移以 UTF-16 代码单元计，结束偏移不包含在区间内。 |
| `extraction-report.md` | 供人工浏览的成员、诊断和支持范围说明。 |

在交付根目录运行下面的命令可以复跑 Smart Library 例子。`example-output` 需要是新目录或空目录。

```powershell
javac -encoding UTF-8 -d build-extractor "主体/02-Java骨架提取器/tools/JavaTestSkeletonExtractor.java"
java -cp build-extractor JavaTestSkeletonExtractor --input "样例材料/骨架样例输入/smart-library/DefaultBorrowPolicyUnitTest.java" --output example-output
```
