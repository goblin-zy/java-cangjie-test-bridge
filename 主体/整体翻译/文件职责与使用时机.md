# 文件职责与使用时机

本文用于在整体任务中解释具体文件，执行顺序以 translate_whole.md 为准。无需把全部索引、所有逐条上下文和所有源码同时交给 Agent。

## 启动与同版材料

| 文件 | 内容 | 使用时机 |
| --- | --- | --- |
| config/whole_task.template.json | 项目、范围、工具/材料/骨架路径、策略和输出约束 | Agent 先填真实信息；不是工具原生配置 |
| source_manifest.json | 原来源、source/ 入口、snapshot_id、inventory、scope、issues | 对照文件角色、SHA-256、选中测试和缺项 |
| source/ | 完整项目原字节副本，保留目录 | Java 提取、阅读源码和资源取材的同版基准 |
| project_schema.json | files/types/members/references 及 internal_analysis | 程序读取的项目索引，不默认全文给模型 |
| context_manifest.json | 索引摘要、身份和源快照 | 每次打开索引自动验证 |
| FAILED.json（若有） | 构建失败原因 | 不把该目录作为成功索引继续使用 |

任务配置普通相对路径相对配置文件；源码根/资源根/test_scope 相对 Java 项目；targets.source_file 和 source_path_map 的值相对冻结 source/。source_manifest 的 project_root 相对索引根，节点的 file 相对 source/。schema_version 是机器协议兼容标识，不能按发布历史改写。

## 测试初始材料

| 文件 | 内容 | 使用时机 |
| --- | --- | --- |
| tasks.json | 测试清单、shared 入口、逐条文件及摘要 | 启动核对当前类范围；定位某条材料 |
| agent_context.json | 整类精简视图，保留已纳入源码、缺项、未解析和结构摘要 | 整类翻译默认入口 |
| initial_context.json/.md | 完整证据及可读展示 | 按指针补读诊断、位置和图边，避免反复全文读取 |
| shared.json | 类字段、初始化、构造器、生命周期及其依赖 | 与逐条测试材料同时读取 |
| tests/*.json | 一条测试及必要辅助逻辑、业务接口、资源与缺项 | 需要聚焦该条测试时读取 |

tasks 的文件入口相对 suite 根；tests 文件的 shared_ref.file 相对该测试 JSON 所在目录，通常为 ../shared.json。必须核对共享摘要及 index_id。PROVIDED_BY_SHARED_CONTEXT 的原文在共享文件；COVERED_BY_INCLUDED_SOURCE 的原文已被当前视图完整区间覆盖，均不能理解为空实现。

required_not_included 及 CONTENT_NOT_INCLUDED_BUDGET 说明正文尚未提供；业务方法默认只给接口，语义不清时 read。字符预算只限制纳入正文，不是 token 或整个 JSON 长度。

## 内部分析和按需查询

| 字段/命令 | 内容及处理方式 |
| --- | --- |
| test_structure | 每个成员的顶层步骤入口、检查数量、延迟检查及 analyze 入口；最多列 20 步，remaining_steps 表示剩余 |
| internal_analysis.nodes | 语句/控制容器、父节点、区域、源码区间及引用；源码顺序不等于执行顺序 |
| internal_analysis.checks | 断言位置、识别依据、控制包围、延迟和启用条件 |
| internal_analysis.features | 重载/构造委托等 REVIEW_REQUIRED；source_transformation=UNSUPPORTED |
| analyze | 按成员查节点/检查/特征；--include-source 可附原文，超限明确列缺项 |
| features | 按类型/成员查适配复核项；不输出程序转换 |
| search/read | 找 key 后读实际声明或正文；显示名不唯一时不能选首条 |
| references/resolve | 查已有出/入边和静态目标/候选；不等于运行时派发 |
| resources/file | 查真实资源锚点、文件和配置；不猜未知工作目录 |
| lookup | 查询 build 登记的 JSON 条目；未登记则读本轮真实材料路径 |

断言分 CONFIRMED_STATIC、SOURCE_IMPORT_SUPPORTED、JAVA_ASSERT_SYNTAX 和 CANDIDATE。明确 import 不代表编译器已确认；同名候选不计入已识别检查。Java assert 需要启用条件，lambda 内检查有延迟包围，不能推断实际执行次数。辅助方法须沿真实引用另查，不能把它自动拼成已执行轨迹。

analyze 对 nodes/checks/features 分别使用同一 offset/limit，next_offset 按最长列表；某个列表当前页为空不表示其他列表读完。源码整段超限时留空并记录，不截断成残缺代码。query_log.jsonl 只有程序操作摘要，Agent 对问题、证据与理解另写 context_queries 和 evidence。

## 其他模块交付

| 文件 | 内容 | 使用时机 |
| --- | --- | --- |
| Java original/ | 输入完整源码副本 | 与 source_manifest 文件摘要核对，再读原文 |
| Java skeleton/ | 声明骨架及占位方法体 | 核对结构，不翻译占位异常 |
| Java members.json | files/classes/members/diagnostics；源 ID、角色、原方法体、字段和位置 | 建源成员台账，保留上游真实 ID |
| extraction-report.md | 提取数量、诊断和边界 | 查初始化块、匿名/局部类及成员缺项 |
| 仓颉骨架 .cj | 包、导入、类型、方法、字段和待填内容 | 先完整读取，在副本中填充 |
| member_mapping.json/member-map.json | 源 ID 到目标文件、签名及槽位；字段按实际格式 | 建对应关系，核对 status/fill_slot/adaptation |
| translation_report.json/diagnostics.json（若有） | 骨架结构改动、依据和缺项 | 沿用已确认结构；缺报告不假称已读取 |
| translation_rules.json/.md | 规则条件、语义、依赖、例子与限制 | 遇到相应写法时查真实 rule ID |
| project_materials.json/.md | 项目接口、设施、资源等条目，basis/status/sources/limitations | 查真实 item ID，pending 不自动升级 confirmed |
| 仓颉业务源码及 cjpm.toml | 真实包、声明、签名、行为和环境 | 核验目标调用；不能修改业务迎合译文 |

公共材料类别按其实际 categories 解释，不能将规则分类编号与材料分类编号混用。附加材料若晚于建索引，直接读文件，不为 lookup 重复构建源码索引。

## 三套成员身份与输出

上下文用 source_member_key；Java 提取器用 members[].id；仓颉映射用 source_member_id 加源表路径及目标位置。以同文件摘要、所属类型、完整签名和区间建立对应，不能只凭名称。方法/构造器通常可核对声明区间；字段可能分别定位 VariableDeclarator 与 FieldDeclaration，需名称/类型及包含关系共同确认。多变量、匿名类型或重复声明的歧义保留。

Java 成员表未登记的初始化块可在 class_analysis.additional_source_structures 记录，不伪造源 ID。Java 提取角色与实际框架导入不一致时保留 extracted_role，另记 role_basis。

整体 Agent 输出 input_manifest、member_crosswalk、class_analysis、context_queries/evidence、必要 proposed_contracts、translated/resources、translation_result、checks 与 translation_handoff；目标声明改变才派生 member_mapping.resolved，不回写输入。逐成员证据只记录实际使用条目；新增辅助声明独立记录用途、源关联、委托、语义调整及检查。详细字段以 translate_whole.md 为准。

## 能力边界

源码转换及可执行测试前缀不支持，完整运行时控制流和自动操作—断言因果关系未建立。总体职责与待实现项见 [职责分工](../职责分工与流程.md)。整体翻译输出单位是完整测试类，逐条材料仅用于证据组织。

week12 的同版成员表、执行类关联和填充前结构检查新增接口见 [对接说明](../集成适配/README.md)。Java 提取可先于上下文建索引，仓颉骨架检查位于整体填充之前。
