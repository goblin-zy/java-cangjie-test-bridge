# Java→仓颉测试代码翻译

本分支提供测试代码预处理工具和整体翻译材料。

## 测试代码预处理

选择Java工程中的测试源码与资源目录，保存原文并提取语法结构、引用与特性提示，生成供骨架、上下文及翻译模块读取的文件。

窗口操作：打开week8/启动预处理.cmd → 选择随包样例或实际工程 → 检查环境 → 开始分析 → 查看本轮结果。
