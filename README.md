# 蒋逸舟 · 第八周：仓库预处理与整体翻译

将完整代码库整理为下一步“材料分类”可直接读取的材料包。程序保存文件与工程事实，Agent可补充仓库说明；本步骤不生成翻译骨架或测试译文。

**选择代码库 → 点击预处理 → 可选生成并导入Agent说明 → 整体交给材料分类。**

整体翻译按完整测试类填充已有仓颉骨架。提示词规定输入、成员对应、资源、输出文件和检查要求。
