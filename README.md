# Java → 仓颉测试翻译（hyz · week10）

给定一个含 JUnit 测试的 Java 工程，本项目引导 Agent 收集材料，并用两种方式生成仓颉候选测试，供组员对照。

```text
主体/          翻译流程、程序、规则与模型提示词
样例材料/      积分钱包、图书馆和 Commons IO 的 Java 输入
运行记录/      积分钱包的两次历史试跑
版本更新记录.md
```

Agent 先分析项目，在 translation_config.json 中登记项目路径、测试文件和本轮输出位置。骨架提取器保存 Java 声明与原方法体。材料工具整理接口、辅助方法和测试上下文，覆盖工具记录原 Java 测试实际执行的方法。Agent 根据这些材料生成仓颉骨架，再按整个测试类填充，或逐片段翻译后装配。

在每轮输出中，06-whole-translation 保存整体译文与交接记录，07-fragment-translation 保存片段清单、装配报告和译文。两路输出中的 .cj 文件可供比较，实际编译和测试状态见该轮验证记录。
