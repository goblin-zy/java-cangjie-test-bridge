## 处理流程

```text
完整 Java 项目 → 上下文索引与测试材料
              → 结合规则、公共材料、成员表和仓颉骨架
              → Agent 按需补查 → 完整候选测试与交接文件
```

源码接收、冻结和分析归上下文，骨架及类型适配归对应模块；取消独立预处理入口。源代码转换和可执行测试前缀暂未实现。职责去向及流程图见 [职责分工与流程](主体/职责分工与流程.md)。
