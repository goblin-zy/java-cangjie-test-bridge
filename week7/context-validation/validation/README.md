# 验证材料导航

|目录或文件|用途|
|---|---|
|[context/index](context/index/)|查看Java成员索引、原始源码快照与提取结果|
|[context/export](context/export/)|查看三份测试上下文、选择方案与32条源码证据核对|
|[repository-account-preupload](repository-account-preupload/)|查看九条账户参考测试的历史执行结果、配置和运行环境|
|[evaluation-history](evaluation-history/)|核对正确执行、断言失败、编译错误、零测试、数量不符等历史场景|
|[portable-checks.json](portable-checks.json)|查看已有证据的可迁移性检查结果|
|[integration-checks.json](integration-checks.json)|查看已有集成核对记录|

历史记录保留原始环境与执行时间。本次复核范围见[验证记录](../../../docs/06-整理验证记录.md)。
