# 测试具体上下文查找工具

输入完整项目路径及测试文件或方法标识，找到并导出理解当前测试所需的源码、初始化与清理、辅助逻辑、相关定义和资源。工具只实现方法／样例层上下文查找。

不需要selection.json，不生成翻译骨架、跨层规则组合或完整模型输入。当前工具位于蒋逸舟week7分支的week7/context-lookup。

## 输入与输出

|输入|示例形式|
|---|---|
|项目路径|任意Java工程的根目录|
|测试文件|src/test/java/某包/SomeTest.java|
|方法标识|完整类型名#方法名(参数类型)，或测试文件路径#方法名()|
|结果目录|项目之外尚不存在的新目录|

每次输出两个文件：

- `context_<标识>.json`：范围、原始测试、分类上下文、相关成员标记、未解析引用和停止边界。
- `context_<标识>.md`：按类别展示同一批实际代码和资源，包含来源位置与查找原因。

## 支持情况

支持JUnit4/5的普通测试、常规Maven模块和Java目录、简单继承生命周期、本类和简单类外调用、字段初始化、常量定义、字面量/final字符串路径的部分资源读取。保留完整测试类，并标明本轮实际展开的成员。

未实现编译器级符号绑定与完整调用图。重载、接口动态实现、链式接收者、反射、方法引用、动态资源路径和外部定义可能无法解析；工具明确记录这些情况。输出没有“全部依赖已收集”的保证。
