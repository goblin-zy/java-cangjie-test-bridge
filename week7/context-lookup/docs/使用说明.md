# 使用说明

## 环境

需要Python3.10以上与完整JDK17以上。Python仅使用标准库，无需模型API或额外安装Java依赖。工具只解析输入源码，不执行工程构建、业务或测试。

## 由Agent自动调用

使用者可以直接提出：

> 请使用本工具，对“项目根目录”中的“测试文件或方法标识”查找具体上下文，结果保存到“项目外的新目录”。请读取输出中的实际内容、未解析引用和停止边界，不生成选择文件，不做翻译或规则筛选。

Agent调用下述程序或Python函数，不要求用户生成中间配置。查找逻辑由程序执行；Agent可据未解析项继续阅读，但不能把补充推断写成已经由程序解析的事实。

## 程序命令

在工具目录执行；其中三个路径替换为实际值：

```powershell
python context_tool.py --project 'D:/projects/工程' --target 'src/test/java/包名/SomeTest.java' --output 'D:/runs/context-01'
python context_tool.py --project 'D:/projects/工程' --target '包名.SomeTest#testMethod()' --output 'D:/runs/context-02'
```

第一种以测试类为对象，展开该类识别出的测试方法；第二种聚焦一个方法，但保留完整所在类。不是预先选择依赖片段。

也可使用`--target 测试文件 --method 方法签名`。目标不存在、未识别为JUnit测试、存在歧义或含语法错误时明确报错，不生成看似有效的上下文。

## Python接口

```python
from context_tool import collect
result = collect(project_path, test_file_or_method_id, new_output_directory)
```

结果对象与JSON内容一致。路径使用当前机器实际值，不依赖开发者的本地工程目录。

## 非标准工程与限制参数

- `--source-root 相对目录`：可重复，显式指定本轮源码根，并替代自动发现范围。用于自定义目录或多模块同名类型的范围限定。
- `--resource-root 相对目录`：可重复，增加资源根。目录须位于项目内部。
- `--java`、`--javac`：指定本机工具路径。
- `--max-depth`：依赖调用展开深度，默认6。
- `--max-members`：最大成员展开数量，默认300。保留完整类型可能带入额外周边成员，不等于输出记录数量上限。
- `--max-files`：最大源码索引文件数，默认5000，超出时拒绝处理，不静默截断。
- `--max-resource-bytes`：单份资源内容上限，默认262144字节；超限报告未解析，不只列文件名冒充已提供内容。

输出目录须位于项目之外且尚不存在。完成后阅读JSON/Markdown中的unresolved与project_issues；命令成功仅表示产物已生成，不表示依赖完整或测试可运行。
