# 查找范围与策略

## 工程范围

优先识别工程根目录、Maven声明模块及常规src/main/java、src/test/java与资源目录。Maven的字面自定义路径也可读取，属性和profile等未求值内容记录为问题。Gradle仅根据描述文件和常规目录发现候选，不执行构建脚本。

存在正式工程入口时，不把历史输出中的另一棵src目录自动算作新模块。没有可识别源码根时退回项目目录扫描；实际根和fallback状态写入scope。显式source-root可限定范围。

排除.git、.cache、.gradle、.idea、node_modules、target、build、__pycache__目录，不跟随符号链接与目录联接。Java源码首版要求UTF-8，不能解析的文件说明原因。没有执行Maven effective model或完整模块classpath分析。

## 成员与依赖

1. 确认目标测试及完整所在类，保存原始测试方法和导入。
2. 保守提供目标类及相关类型的字段、初始化和初始化块，理由中标明非最小化收集。
3. 沿简单父类链查找JUnit4/5初始化与清理声明，处理基本方法覆盖；复杂组合注解、扩展机制和接口生命周期不作已解析保证。
4. 追踪目标、准备及辅助方法中的调用，包括lambda内部调用与辅助方法中的断言。
5. 使用当前类型、字段/局部变量声明类型、导入和同包规则定位简单类外接收者；根据方法名及参数数量筛选。无法唯一确定的重载不猜选。
6. 继续读取已找到方法的依赖，按成员标识去重，保留每次查找原因。目标测试类完整保留；其他类型提供声明头、字段和实际追踪到的方法，related_members标记本轮展开成员。

此过程不调用编译器类型绑定，局部变量遮蔽、泛型、动态分派、跨模块同名定义、接口实现、反射和链式调用存在限制。接口或抽象声明找到后，运行时实现仍列为未解析。普通虚调用找到的是声明类型的实现，不构成实际运行分派证明。

## 资源

支持getResource/getResourceAsStream的直接字符串路径，部分final字符串字段，以及Path.of、Paths.get、File/FileInputStream/FileReader的简单字面路径。类相对资源考虑包路径；类加载器资源按根目录查询。资源名冲突、动态路径、父目录跳转、项目外路径与大小超限均明确停止。

UTF-8资源提供原始文本；其他资源提供完整Base64字节及编码标记。动态拼接、通过参数传入的路径、数据库内容、网络响应和链式文件API并未完整求值，不能凭文件名猜出内容。

## 停止条件

- 外部库或JDK定义不在本项目：记录调用原文、位置及未解析原因，不复制框架内部源码。
- 方法、类型或资源有多个候选：记录歧义与候选，不自动选一个。
- 接口动态实现、方法引用或资源路径无法确定：报告未解析。
- 成员已访问：停止重复展开，递归调用不会无限循环。
- 达到深度、成员或资源大小上限：保留未处理项与停止原因。

completeness始终为NOT_ESTABLISHED。没有未解析项也不能证明涵盖所有框架语义。
