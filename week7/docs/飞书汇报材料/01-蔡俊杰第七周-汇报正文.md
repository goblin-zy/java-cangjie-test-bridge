# 蔡俊杰第七周

负责内容：Java测试骨架提取、参考仓颉测试。

## 本周主要步骤

1. 整理账户、矩形、指令解析三个Java业务类及其24个JUnit测试。
2. 使用JDK语法树实现测试骨架提取，保留声明和签名，保存原始方法体，输出骨架和members.json。
3. 验收单文件、目录、重载、嵌套类、构造器委托、语法错误和输出保护；检查原方法体能按位置回填。
4. 整理三个模块的参考仓颉测试，对照Java输入、操作与预期结果。
5. 编译执行参考测试，并用四种独立错误实现检查测试能否发现错误。
6. 将Java代码统一为Maven项目，配置VS Code测试入口；仓颉支持全部、按类和单项测试任务。

## 如何复现

1. 获取仓库，在VS Code中单独打开week7目录。
2. 安装JDK17及Java测试扩展，等待Maven导入，打开测试类点击Run Test。
3. 运行提取器时选择“提取业务测试骨架”，输入新的输出目录，检查骨架和members.json。
4. 仓颉需准备匹配的SDK及运行库，在工作区设置中修改SDK路径。
5. Ctrl+Shift+P → Tasks: Run Task → 运行仓颉参考测试（24项）或运行单个仓颉测试。
6. 单项输入AccountTest.testWithdraw；按类输入RectangleTest.*。详细步骤见附带文档。
