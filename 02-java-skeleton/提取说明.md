# Java 测试骨架提取

通用输入是 Java 源文件或目录，文件可以来自不同项目。将预处理后需要纳入翻译的测试、基类和辅助源码传给 `--input`。提取使用第七周提交 6105b07 的 JavaTestSkeletonExtractor。程序使用 JDK 17 javac 语法树定位声明和方法体边界。

每次输出到 `--output` 指定的目录，包含 original/ 原文件副本、skeleton/ 骨架、members.json 成员元数据和 extraction-report.md 提取报告。方法体占位，原方法体保存在成员表。字段声明和原初始化表达式保留，便于后续判断目标字段如何初始化。本次分别用两个固定版本的原测试文件验收，产物放在 smart-library 和 commons-io。

- Smart Library 提取 5 个普通测试成员。
- Commons IO 提取 9 个测试方法和 3 个字段，共 12 个成员。

GitHub 分支先运行 prepare_inputs.py 获取输入。在交付根目录也可单独复现以下操作。输出目录需为新目录或空目录。

```powershell
javac -encoding UTF-8 -d build-extractor 02-java-skeleton/tools/JavaTestSkeletonExtractor.java
java -cp build-extractor JavaTestSkeletonExtractor --input 01-projects/commons-io/src/test/java/org/apache/commons/io/ByteOrderMarkTest.java --output extracted-io
python 03-cangjie-skeleton/check_skeleton.py
```
