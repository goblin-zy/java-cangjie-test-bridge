# 静态验证的钱包输入

本目录补齐静态验证原有回归所需文件。points-wallet/ 是上游随分支提供的 Java 样例；Translation-all/ 保留可直接用于旧验证接口的同版项目、骨架、映射和最终译文。

Translation-all 的材料取自团队基线 8cc9485。为搬迁测试，translation_config.json 的项目路径改为仓库内相对路径；缺失的 Java 提取目录用蔡俊杰 week12 提取器生成。来源与原文件摘要见 Translation-all/来源.json，不包含作者本机公共材料扫描缓存。

这些是钱包历史翻译的回归输入，不是本次重新生成的翻译。静态验证原有 14 项测试已用这些文件实际跑通；可读结果见 [原静态验证报告](../../运行记录/静态验证/points-wallet-whole/deliverables/report.md)，本次三部分整合使用另一个 [Interval 项目](../Interval双语项目/java)。
