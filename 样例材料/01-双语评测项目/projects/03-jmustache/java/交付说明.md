# Java 业务和原测试

`src/main/java/` 存放 JMustache 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/com/samskivert/mustache/SharedTests.java)。

测试使用 JUnit 4，`SharedTests.java` 由同目录的 `MustacheTest.java` 继承，脚本通过后者发现和执行测试。

源码来源为[上游固定提交 `6a00bc75`](https://github.com/samskivert/jmustache/tree/6a00bc7547191b8a865ccd5887a077e7eb825255)。
