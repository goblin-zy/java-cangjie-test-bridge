# Java 业务和原测试

`src/main/java/` 存放 java-diff-utils 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/diffutils/DiffTest.java)。

原测试使用 JUnit 3 风格，由 JUnit Vintage 引擎执行。

源码来自 [Google Code 归档](https://storage.googleapis.com/google-code-archive-source/v2/code.google.com/java-diff-utils/source-archive.zip)，使用 `java-diff-utils/branches/1.3.0`。归档 SHA-256 为 `bc3aff1c521e239992ab22b2a4ded1cdd76dd6c6a1b8da72e7116b48c1438544`。
