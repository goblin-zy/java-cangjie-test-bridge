# Java 业务和原测试

`src/main/java/` 存放 Commons Codec Base32 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/org/apache/commons/codec/binary/Base32Test.java)。

使用 JUnit 5，实际选择 `testBase32Samples`。编译原测试类还用到同包的 `BaseNTestData.java`。

源码来源为[上游固定提交 `96510970`](https://github.com/apache/commons-codec/tree/965109705c5236b05011e1c45f47d991abfa521e)。
