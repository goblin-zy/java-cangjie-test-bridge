# Java 业务和原测试

`src/main/java/` 存放 Juniversalchardet 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/org/mozilla/universalchardet/BasicFileEncodingDetectionTest.java)。

使用 JUnit 4，`src/test/resources/` 是测试按相对路径读取的编码样本。

源码来源为[上游固定提交 `9236c5a0`](https://github.com/albfernandez/juniversalchardet/tree/9236c5a034bb5b33d1fcb947e33a76c6b2ebb78b)。
