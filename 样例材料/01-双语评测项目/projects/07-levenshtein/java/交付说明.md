# Java 业务和原测试

`src/main/java/` 存放 Commons Text 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/org/apache/commons/text/similarity/LevenshteinDistanceTest.java)。

实跑的是 JUnit 5 方法 `testGetLevenshteinDistance_StringString`，使用 AssertJ 表达 10 条检查。

源码来源为[上游固定提交 `2c2d0818`](https://github.com/apache/commons-text/tree/2c2d0818b0540c59f055f5174db51d0574af46da)。
