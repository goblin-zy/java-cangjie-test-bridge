# Java 业务和原测试

`src/main/java/` 存放 jsoup 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/org/jsoup/select/SelectorTest.java)。

原测试使用 JUnit 5，编译该测试还需要 `src/test/java/org/jsoup/MultiLocaleExtension.java` 和 `src/test/java/org/jsoup/TextUtil.java`。

源码来源为[上游固定提交 `becdd2e1`](https://github.com/jhy/jsoup/tree/becdd2e118639ee603be0c12eda216cb0e01fe29)。
