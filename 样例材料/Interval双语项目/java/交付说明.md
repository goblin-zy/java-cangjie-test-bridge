# Java 业务和原测试

`src/main/java/` 存放 Aho-Corasick 的业务实现，`src/test/` 存放上游测试及适用的样本。评测使用[这份 Java 原测试](src/test/java/org/ahocorasick/trie/TrieTest.java)。

使用 JUnit 4。测试类依赖同包的 `TestHelper.java`。

源码来源为[上游固定提交 `e68720d0`](https://github.com/robert-bor/aho-corasick/tree/e68720d0afd51093fbba1232edf154ad71a62ac3)。
