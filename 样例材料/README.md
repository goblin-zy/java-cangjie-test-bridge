# 样例材料

| 工程 | 用途 |
|---|---|
| [points-wallet](points-wallet/) | 小型积分钱包，适合首次试用。运行记录中的两组历史输出均来自本样例。 |
| [smart-library](smart-library/) | 图书借阅资格判断，展示测试与多个业务类型之间的依赖。 |
| [commons-io](commons-io/) | Apache Commons IO 源码快照，可从 ByteOrderMarkTest 开始分析。 |

把选定工程的目录作为 PROJECT。上游版本、测试入口和选取理由见[项目选取](项目选取.md)及 [sources.json](sources.json)。许可证与来源说明随材料保存。
