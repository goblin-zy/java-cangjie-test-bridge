# 异常处理

|现象|处理方式|
|---|---|
|双击后没有窗口|检查Python和Tkinter；系统限制VBS时改用Python打开tools/preprocess_gui.pyw|
|提示输出目录已存在或位于输入内部|在代码库外填写一个尚不存在的新目录|
|找不到java或javac|选择完整JDK中对应的exe文件；仅整理文件时可保留未提取结构的结果|
|完成但存在语法错误|查看issues；保留原文件，确认是否为仓库自带的非法样例，不应直接删除|
|点击导入说明后出现文件选择框|选择Agent已生成的agent-result.json；尚未生成则取消，按教程先生成|
|Agent说明版本不一致|根据本轮任务和模板重新生成，不修改版本号绕过校验|
|Agent说明引用不存在的文件|让Agent按files.json中的真实ID修订|
|报告未读分片|说明Agent分析尚未覆盖这些内容，未知范围随包交接|

正常流程无需逐文件人工审批。使用者主要确认工程根目录和输出位置，并在需要时处理环境缺失或输入范围问题。
