# 样例测试运行

此目录保存一组ListTest测试的实际预处理结果。源码位于结果/input/src/test/java/sample/ListTest.java，资源位于结果/input/src/test/resources/message.txt。阅读和复跑使用同一份源码。

样例包含准备清理、添加后清空的状态测试、资源访问及同名辅助方法。输入采用JUnit注解，预处理执行Java语法解析；测试运行环境由下游配置。

## 文件与用途

| 文件 | 用途 |
| --- | --- |
| 结果/input/ | 唯一样例源码与资源 |
| 结果/handoff.json | 分析入口及状态 |
| 结果/members.json | 成员原文与定位 |
| 结果/translation_features.json | 注解名称与重载等语法提示 |
| 结果/downstream_handoff.json | 模块交接要求 |
| 运行记录.txt | 实际分析与检查结果 |

## 在窗口中复跑

1. 双击工具根目录的启动预处理.cmd。
2. 点击“使用随包样例”，核对工程路径和测试、资源目录。
3. 选择工程之外的结果保存位置。
4. 点击“检查环境”，通过后点击“开始预处理分析”。
5. 完成后点击“打开本轮结果”或“查看本轮说明”。

每轮自动创建新结果目录。此处的结果/保留随包的实际输出，新的运行保存到窗口选择的位置。
