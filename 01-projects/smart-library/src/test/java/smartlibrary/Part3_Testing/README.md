# Part 3 – Unit, Integration, and System Testing

This folder corresponds to **Part 3 (10 points)** of the project.

In this part, the team implemented:
- Unit Tests
- Integration Tests
- System Tests

The work is split among team members to ensure individual contributions
without duplication. Test cases are documented with:
- Expected output
- Actual result
- Description and Reason for the test
- Test type (Unit / Integration / System)
- Responsible team member
