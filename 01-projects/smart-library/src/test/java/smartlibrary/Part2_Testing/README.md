# Part 2 – Testing Analysis

This folder corresponds to **Part 2 (5 points)** of the project.

Each team member is responsible for performing **testing analysis on distinct
methods** from the project. The analysis includes:

- Boundary Value Testing (BVT)
- Equivalence Class Testing or Decision Table Testing
- Code Coverage Analysis:
    - Statement Coverage
    - Branch Coverage
    - Condition Coverage
    - MC/DC Coverage

Each member documents their analysis individually (maximum 2 pages),
as required by the project instructions.
